## Instructions

This entry registers **webmcp** as a house module. It adds one registry of
agent tools (`app/tools/`, built on the official `mcp` gem) that serves both an
MCP server and WebMCP browser tools. Signed-in pages register the tools on the
browser's model context (`document.modelContext`, falling back to
`navigator.modelContext`) and unregister them on sign-out. Each call goes
through a session-authenticated, CSRF-protected JSON endpoint.

This is an explicit new-module adoption. The changelog filter skips the entry
until `webmcp` is present in the downstream manifest, so apply these
instructions only after the maintainer chooses the module. Requires the `auth`
module (`Authentication`, `Current.session`) and the `frontend` module (Inertia
shared props, `inertia.tsx`, layout).

1. Copy `docs/modules/webmcp.md` from the template into the app's
   `docs/modules/`.
2. Follow that doc's "Adopt into an existing app" steps: the `mcp` gem,
   `app/tools/` (`ApplicationTool`, `ToolRegistry`, the example `WhoamiTool`),
   `WebmcpToolsController` and its `webmcp_tool` route, the `webmcp`
   `inertia_share`, `app/frontend/lib/webmcp.ts` + `webmcp_provider.tsx` +
   `types/webmcp.d.ts` and the `WebmcpProvider` wrapper in `inertia.tsx`, the
   optional origin-trial initializer, layout `<meta>` loop, and
   `WEBMCP_ORIGIN_TRIAL_TOKEN` deploy variable, the `tool` generator (plus
   `generators` in `config.autoload_lib(ignore:)`), and the tests.
3. If the app already exposes MCP tools (for example `MCP::Tool` classes or a
   `fast-mcp` `ApplicationTool`), reconcile rather than duplicate: make them
   subclass the template's `ApplicationTool` (or port their `call` into
   `#call`) and list them in `ToolRegistry::TOOLS`, so the MCP server and
   WebMCP read the same definitions. Keep the app's existing MCP transport and
   credentials; point it at `ToolRegistry.mcp_server(user:)`.
4. Add the app's `AGENTS.md` "Agent tools (WebMCP + MCP)" section from the
   template, and `webmcp` to its module enumeration.
5. Run the verification below. Only after it succeeds, add
   `webmcp: "0.8.0"` to `.template-manifest.yml` and set `template_version`
   to at least `"0.8.0"`, never lowering a newer value.

For an app that does not want agent tools: no action. This entry only affects
apps that list `webmcp` in their manifest.

## Verify

- `bin/rails test test/tools test/controllers/webmcp_tools_controller_test.rb test/integration/webmcp_test.rb test/generators/tool_generator_test.rb`
  passes; `npm run check` is green.
- Signed out, `POST /webmcp/tools/whoami` answers `401` JSON; signed in, an
  Inertia page's props include `webmcp.tools`.
- `bin/rails g tool Ping --pretend` lists `app/tools/ping_tool.rb`,
  `test/tools/ping_tool_test.rb`, and the `tool_registry.rb` insert.
