## Instructions

This entry adds **copse** ([github.com/kieranklaassen/copse](https://github.com/kieranklaassen/copse))
as a default development module: deterministic per-app and per-worktree dev
hostnames, ports, and databases.

For a downstream app adopting it:

1. Add to the `Gemfile` `development` group:

   ```ruby
   gem "copse"
   ```

2. Run `bundle install`, then `bin/rails generate copse:install`. The generator
   rewrites `bin/dev` — if your `bin/dev` carries custom steps, port them into
   `Procfile.dev` entries instead.
3. Reorder `Procfile.dev` so `web:` is the FIRST entry (overmind assigns each
   process `base + index * 100`; web must own the base port). Keep `vite:` (or
   other processes) after it.
4. Copy `docs/modules/copse.md` from the template into the app's `docs/modules/`.
5. Add `copse: "0.3.0"` to `.template-manifest.yml` and bump `template_version`
   to `"0.3.0"`.

## Verify

- `bundle list | grep copse` shows the gem.
- `head -5 bin/dev` shows copse's ruby launcher.
- `head -1 Procfile.dev` starts with `web:`.
- `bin/dev` boots and prints the derived hostname/port; `bin/rails test` is green.
