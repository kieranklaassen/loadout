## Instructions

This entry establishes the **0.1.0 baseline**. A fresh clone of the template is
already at `template_version: 0.1.0` with every module adopted, so there is
nothing to apply — the app is born complete.

For an **existing app converging on the template** for the first time, adopt the
modules you want one at a time, each via its boundary doc's
"Adopt into an existing app" section:

1. Pick a module from [`docs/modules/`](../modules/README.md) (start with
   `frontend` or `auth`).
2. Follow that doc's adoption steps and run its "Verify adoption" command.
3. Add the module to the app's `.template-manifest.yml` at `"0.1.0"`.
4. Repeat per module; open a reviewable PR (never a direct push).

## Verify

- `bin/rails test` and `npm run check` are green.
- `.template-manifest.yml` lists each adopted module at `"0.1.0"`.
