## Instructions

Update every GitHub Action in `.github/workflows/*.yml` to its latest release,
keeping the SHA-pinned form, and let Dependabot watch npm too so JavaScript
drift gets PRs like gems and actions already do.

1. Replace each `uses:` line (including commented-out jobs such as
   `system_test`) with:

   ```yaml
   uses: actions/checkout@3d3c42e5aac5ba805825da76410c181273ba90b1 # v7.0.1
   uses: actions/cache@55cc8345863c7cc4c66a329aec7e433d2d1c52a9 # v6.1.0
   uses: actions/setup-node@820762786026740c76f36085b0efc47a31fe5020 # v7.0.0
   uses: ruby/setup-ruby@762794c140bbeda0f1224786aa33b4b46783a6c1 # v1.326.0
   ```

   Keep each step's existing `with:` block. The template's `node-version-file:
   .node-version` + `cache: npm` and `bundler-cache: true` inputs work unchanged
   on these majors, and ruby/setup-ruby 1.326.0 installs Ruby 4.0.7 from
   `.ruby-version`.
2. In `.github/dependabot.yml`, add an npm entry alongside the bundler and
   github-actions entries:

   ```yaml
   - package-ecosystem: npm
     directory: "/"
     schedule:
       interval: weekly
     open-pull-requests-limit: 10
   ```

3. Close any open Dependabot PRs for these four actions; this entry supersedes
   them.

## Verify

- `grep -rn "uses:" .github/workflows` shows only the four SHAs above (plus any
  app-specific actions, each also updated to its latest release).
- Push the branch and confirm every CI job (`scan_ruby`, `lint`, `check_js`,
  `test`) passes.
