## Instructions

This entry registers **ruby_native** ([rubynative.com](https://rubynative.com/))
as a house module: native iOS/Android distribution for the app without
Swift/Kotlin. The module is **documentation-first** — no gem, no license, no
secrets ship in the template.

For a downstream app that wants native distribution:

1. Copy `docs/modules/ruby_native.md` from the template into the app's
   `docs/modules/` (create the directory if absent).
2. Follow that doc's "Adopt into an existing app" steps (license, gem,
   generator, env-var placeholders only).
3. Add `ruby_native: "0.2.0"` to the app's `.template-manifest.yml` and bump
   `template_version` to `"0.2.0"`.

For an app that does not want native distribution: no action — this entry only
affects apps that list `ruby_native` in their manifest.

## Verify

- `docs/modules/ruby_native.md` exists in the app.
- If adopted: the gem is bundled, `config/ruby_native.yml` exists, and
  `git grep` finds no license keys in it.
- `bin/rails test` is green.
