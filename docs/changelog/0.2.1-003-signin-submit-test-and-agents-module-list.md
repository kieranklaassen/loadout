## Instructions

Two small hardening fixes:

1. **Sign-in submit coverage** (`auth` module): in
   `app/frontend/pages/auth/sign_in.test.tsx`, hoist the mocked `post` into a
   shared `const post = vi.fn()` and add a test that `fireEvent.submit`s the
   form, asserting `post` was called with `'/session'` and that the submit

   Without it, dropping `event.preventDefault()` silently breaks sign-in.

   docs/modules list in `AGENTS.md` enumerate every module in
   `.template-manifest.yml` (it was missing `frontend`).
