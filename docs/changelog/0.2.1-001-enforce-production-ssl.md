## Instructions

Production SSL enforcement was commented out, so the auth session cookie
shipped without `Secure` and no HSTS was emitted. Enable it:

1. In `config/environments/production.rb`, ensure these are active
   (uncommented):

   ```ruby
   config.assume_ssl = true
   config.force_ssl = true
   config.ssl_options = { redirect: { exclude: ->(request) { request.path == "/up" } } }
   ```

2. If your app terminates TLS somewhere other than a proxy in front of the app
   (unusual for the Kamal module), verify `assume_ssl` matches your topology
   before enabling.

## Verify

- `grep -E "^\s*config\.(assume_ssl|force_ssl) = true" config/environments/production.rb` matches both lines.
- `bin/rails test` is green.
