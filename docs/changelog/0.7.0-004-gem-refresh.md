## Instructions

Bring the bundle current: Rails 8.1.4, image_processing 2.x, and the latest
compatible release of every other gem. This supersedes the template's Dependabot
bumps for bootsnap, copse, image_processing, selenium-webdriver, solid_queue and
thruster.

1. In `Gemfile`:
   - set `gem "rails", "~> 8.1.4"` (drop the older `"~> 8.1.3", ">= 8.1.3.1"`
     pair);
   - set `gem "image_processing", "~> 2.1"` and, directly below it, add

     ```ruby
     # image_processing 2.x no longer pulls in its backend; Active Storage variants use libvips
     gem "ruby-vips", "~> 2.2"
     ```

     image_processing 2.0 made `ruby-vips` and `mini_magick` soft dependencies.
     Without `ruby-vips` in the Gemfile, boot fails with
     `LoadError: ImageProcessing::Vips requires the ruby-vips gem`. If the app
     configured `config.active_storage.variant_processor = :mini_magick`, add
     `gem "mini_magick", "~> 5.4"` instead.
   - Keep every other version pin the app already has for a documented reason
     (for example a `kamal` pin tied to a shared host's `kamal-proxy`). Remove
     pins that have no stated reason.
2. Run `bundle update --all`, then `bundle outdated`. The only gems that should
   remain listed are those held by an upstream constraint: `json` (ruby_llm 2.0
   requires `< 3`) and `marcel` (Active Storage requires `~> 1.0`). Investigate
   anything else before accepting it.
3. Expected versions after the update (template lockfile): rails 8.1.4,
   bootsnap 1.26.0, solid_queue 1.7.0, solid_cable 4.1.0, thruster 0.1.26,
   image_processing 2.1.0, vite_ruby 3.11.0, copse 0.2.0,
   selenium-webdriver 4.49.0, rubocop 1.91.0, rack 3.2.7.
4. Run `bin/rails app:update` only if the app wants Rails' new framework
   defaults; 8.1.3 to 8.1.4 is a patch release and needs no config changes.

## Verify

- `bin/rails test` is green, including any Active Storage variant tests.
- `bin/rails runner 'require "image_processing/vips"; puts ImageProcessing::VERSION'`
  prints 2.1.0 or newer.
- `bin/rubocop`, `bin/brakeman --no-pager` and `bin/bundler-audit` pass.
