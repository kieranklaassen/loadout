## Instructions

`RIFFREC_API_KEY` was modeled as a Kamal secret while also being shipped to the
browser in page props — an adopter supplying a genuinely secret key would leak
it. The key is browser-publishable, so name and route it that way:

1. Rename the env var `RIFFREC_API_KEY` to `RIFFREC_PUBLIC_KEY` everywhere:
   `config/initializers/riffrec.rb`, `.env.example`,
   `test/controllers/riffrec_share_test.rb`, and your deployment env.
2. In `config/deploy.yml`, remove `RIFFREC_PUBLIC_KEY` (formerly
   `RIFFREC_API_KEY`) from `env.secret` and add it to `env.clear` as
   `RIFFREC_PUBLIC_KEY: "<%= ENV.fetch("RIFFREC_PUBLIC_KEY", "") %>"`.
3. Remove the `RIFFREC_API_KEY` line from `.kamal/secrets`.
4. Never put a server-side secret in this variable — it travels to the client.

## Verify

- `git grep RIFFREC_API_KEY` returns nothing.
- `bin/rails test test/controllers/riffrec_share_test.rb` is green.
