# Module: copse

[Copse](https://github.com/kieranklaassen/copse) gives every app — and every
git worktree of it — its own deterministic dev hostname, port, and development
database. `fix-billing.myapp.localhost:4783` instead of everything fighting
over `localhost:3000`. No daemon, no reverse proxy, zero runtime dependencies.

## What this module is

- `gem "copse"` in the `development` group.
- `bin/dev` is copse's launcher (generated by `bin/rails generate copse:install`):
  it derives host/port from the directory and branch, provisions a per-worktree
  dev database, and hands `Procfile.dev` to overmind (foreman fallback), keeping
  the web process debugger-friendly.
- `Procfile.dev` keeps `web` **first** — overmind assigns each process
  `base + index * 100`, so the web process must own the base port.

## Files (the module boundary)

- `Gemfile` (`gem "copse"`, development group)
- `bin/dev` (copse launcher)
- `Procfile.dev` (web first, then vite)

## Adopt into an existing app

1. Add `gem "copse"` to the `development` group and `bundle install`.
2. Run `bin/rails generate copse:install` (it rewrites `bin/dev`; review the
   diff if your `bin/dev` carried custom steps).
3. Ensure `web` is the first entry in `Procfile.dev`.
4. Start with `bin/dev`; note the assigned hostname/port it prints.

## Verify adoption

- `bundle list | grep copse` shows the gem.
- `head -5 bin/dev` shows the ruby copse launcher (not the stock sh script).
- `head -1 Procfile.dev` starts with `web:`.
- `bin/rails test` stays green.
